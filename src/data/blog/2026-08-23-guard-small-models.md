> 大模型的安全不是抽象的“有害内容”四字，而是一线客服、风控、政务中每天都会撞见的具体对话。

最近一段时间，我把业余时间花在了一件有点反潮流的事上：写了一本讲**小模型**的书——《守护大模型的小模型》，副标题是“写给安全工程师与模型从业者的小模型安全实践”。已开源在 [open-books/guard-small-models](https://github.com/donge/open-books)，**[下载 PDF](https://github.com/donge/open-books/releases/download/guard-small-models-v0.2.4/guard-small-models-v0.2.4.pdf)**。

为什么是小模型？因为安全检测必须在同步链路上完成。大模型做一次生成要几十毫秒，而小模型做一次分类只要零点几到几毫秒。书中的核心观点是**分层防御**：正则处理格式问题，小模型处理语义问题，策略引擎处理权限问题——大模型只在灰区做解释和仲裁，而不是让一个模型包办所有风险。

## 这本书讲了什么

全书 8 章，围绕一个可复现的 `SmallGuard` 项目展开（3757 条样本，同一份 8:1:1 分组切分，全部实验可审计）：

| 章 | 主题 | 一句话 |
|---|---|---|
| 1 看见风险 | 风险与载体 | 六类风险 × 四种载体，模型只提供信号 |
| 2 读懂语言 | 语言表征 | 分词、Attention、预训练与微调的直觉 |
| 3 数据为镜 | 数据与评估 | 分组防泄露、FPR 约束的阈值选择 |
| 4 百花齐放 | 模型选型 | TF-IDF / CNN / BGE / Qwen 的对比 |
| 5 算力棋盘 | 部署成本 | ONNX、量化、延迟与资源 |
| 6 以尺量尺 | 持续评测 | Bench 与自建回归集 |
| 7 闭环成城 | 工程化 | 灰度发布、回流与 MLOps |
| 8 可验证系统 | 上线证据 | 可复现清单与审计 |

适合三类读者按需阅读：安全工程师重点看 1、3、6、7 章；模型从业者从 1、4 章切入；决策者看 1、4、5、7 章的结论与清单即可。

书中没有追求单点最高的分数，而是强调可验证的过程——比如集成模型曾在 test 上“刷”到最高分，但因用了测试集调参而被判为无效；BGE 与 CNN 各有长短，同分布与跨分布下的表现不同，需要按业务代价选择阈值与模型。
